# Сервис сокращения ссылок

Консольное приложение на Java, которое создаёт короткие ссылки с лимитом переходов и сроком действия.
Владелец может изменить исходный URL, изменить лимит или удалить ссылку.

## Запуск

Для запуска нужен JDK 21
Из корня проекта выполните команду:

```bash
./gradlew run
```

Gradle сам скачает нужные зависимости (например, библиотеку GSON).
Настройки читаются из файла `application.properties` в корне проекта

## Использование

| Пункт меню | Действие                                                       |
|------------|----------------------------------------------------------------|
| `1`        | Создать короткую ссылку: ввести URL и лимит переходов          |
| `2`        | Открыть короткую ссылку или её восьмисимвольный код            |
| `3`        | Показать свои ссылки, счётчики и сроки действия                |
| `4`        | Изменить лимит своей ссылки                                    |
| `5`        | Изменить исходный URL своей ссылки                             |
| `6`        | Удалить свою ссылку                                            |
| `7`        | Переключиться по UUID или ввести `new` для нового пользователя |
| `8`        | Показать справку                                               |
| `0`        | Выйти                                                          |

Пример работы:

1. Выберите `1`, введите `https://example.com/article` и лимит `2`.
2. Сохраните выданный UUID и адрес вида `https://short.local/a1b2c3d4`.
3. Вставьте короткую ссылку в меню дважды. Оба раз откроется исходный URL.
   После второго перехода появится уведомление об исчерпании лимита. Третий переход будет недоступен.
4. Через пункт `4` увеличьте лимит до `3`. Ссылка станет доступна ещё для одного перехода.
5. Через пункт `7` введите `new` и сократите тот же URL. Новый пользователь получит другой код.
   Чтобы вернуться к первому пользователю, введите его UUID через пункт `7`.

Адреса `short.local` используются внутри приложения. Для перехода нужен браузер в графической среде:
приложение открывает исходный URL через `Desktop.browse()`. Если браузер открыть не удалось, переход не учитывается.

## Настройки и хранение данных

| Параметр в `application.properties` | По умолчанию           | Назначение                                  |
|-------------------------------------|------------------------|---------------------------------------------|
| `link.ttl.seconds`                  | `86400`                | Срок действия новой ссылки в секундах       |
| `link.default-limit`                | `10`                   | Лимит, если пользователь нажал Enter        |
| `link.max-limit`                    | `100000`               | Максимальный допустимый лимит               |
| `short.url.prefix`                  | `https://short.local/` | База коротких адресов                       |
| `data.file`                         | `data/links.json`      | Файл данных, путь относительно конфигурации |

Все параметры обязательны. TTL и лимиты должны быть положительными целыми числами,
а лимит по умолчанию не должен превышать максимальный.

UUID создаётся вместе с первой ссылкой. Пользователи, ссылки, счётчики и уведомления сохраняются в JSON между запусками.
Изменять и удалять ссылку может пользователь с UUID её владельца.

При изменении URL или лимита счётчик и срок действия сохраняются. Если новый лимит
не больше уже выполненного числа переходов, ссылка блокируется. Увеличение лимита
восстанавливает доступ, пока срок не истёк.

TTL задаётся конфигурацией и применяется к новым ссылкам. Просроченные ссылки удаляются при запуске и перед командами.
Уведомления об истечении срока и исчерпании лимита показываются владельцу
сообщения для другого пользователя сохраняются до переключения на него.

## Структура проекта

Основной код находится в `src/main/java/ru/linkshortener`, тесты - в `src/test/java/ru/linkshortener`.

| Класс         | Назначение                                                     |
|---------------|----------------------------------------------------------------|
| `Main`        | Меню, ввод пользователя и открытие браузера                    |
| `ShortLink`   | Данные ссылки, проверка URL и срока действия                   |
| `LinkService` | Создание ссылок, учёт переходов, права владельца и уведомления |
| `FileStorage` | Чтение и запись JSON с помощью Gson                            |
| `AppConfig`   | Загрузка и проверка конфигурации                               |

Ссылки и уведомления хранятся в `HashMap`, UUID пользователей - в `HashSet`.
Срок проверяется перед открытием браузера, переход учитывается после успешного открытия.

## Тестирование

Тесты написаны на JUnit и запускаются через:

```bash
./gradlew test
```

Полная сборка с тестами и проверкой оформления:

```bash
./gradlew build
```

Проверяются уникальность ссылок, несколько пользователей, права владельца, лимиты,
изменение параметров, TTL, уведомления, сохранение данных и ошибки ввода.
Консольные тесты проверяют последовательности команд, подменяя открытие браузера.
Отдельный тест проверяет истечение TTL между проверкой ссылки и учётом перехода.
Gson, JUnit и Checkstyle загружаются через Gradle.

Отчёт тестов: `build/reports/tests/test/index.html`.
Отчёты Checkstyle: `build/reports/checkstyle/main.html` и `build/reports/checkstyle/test.html`.
Правила оформления находятся в `config/checkstyle/checkstyle.xml` и `.editorconfig`.
